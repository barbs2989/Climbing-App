# Full-app bug audit — 2026-07-30

Audited at `origin/main` e6e6106 (PRs through #464). Method: ten scoped review passes
(Today, Discover, Climbs browser, route-detail info tabs, planner/safety, crew
lifecycle, messaging/groups, Logbook/Ranks, Me/profile, contribute/auth/shell, plus a
computational-core pass), each tracing every claim to a concrete triggering input.
PRs #457–#464 merged mid-audit, so all high-severity findings from the two earliest
passes were re-verified against e6e6106; line numbers below are current at that commit.
Live-DB claims (string coords, waypoint fallbacks, obj_haz counts) were checked against
the production Supabase data, not seed.

Severity: **H** = crash, data loss/corruption, or a primary flow broken in production
config (USE_DB). **M** = wrong data shown, dead feature, or dishonest copy. **L** = minor,
latent, or demo-only.

Counts: ~130 distinct findings — 41 H, 55 M, ~34 L. Recurring root causes:

1. **Seed-shaped assumptions on the DB path** — `routeById`/`MOUNTAINS.find`/`CLIMBERS.find`
   resolve only seed data; uuid vs `id 0` identity mismatches. (D2, D3, R8, W7, M5, L17, E-series.)
2. **Write-path field maps drifting from read paths** — snake/camel and name mismatches
   silently drop fields. (L2 `fa`/`fa_ascent`, L3 tickType, L5 partners, X1 whitelist, comment authorName.)
3. **RLS-rejected writes swallowed and presented as saved.** (W1, W3, W9, W11, L11.)
4. **Copy asserting mechanisms that do not exist.** (E1 catch confirmation, W8/W16, M6 "Seen",
   M8/M9, P7 offline pack, X10 provenance confirm.)
5. **Fabricated/hash-derived data presented as real.** (A1 availability, D7 mutual friends,
   E6 "government ID", A10 years climbing.)

## Crashes (app blanks; no error boundary exists)

- **H P1** `ClimbMatch.jsx:3355/3362` + `lib/db.js:659` — WeatherPanel calls `w.lat.toFixed(4)`

  rating > 5 or non-numeric; guarded today only by data discipline.
- **L M12** `ClimbMatch.jsx:1285` — mention regex built from unescaped profile names; a `(`
  in a first name throws inside the submit handler (dead submit).
